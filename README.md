# WorkSphere HR — React Internship Project

WorkSphere is a responsive, frontend-only employee management and payroll web application built for an internship demonstration.

## Pages included

1. Dashboard
2. Employees
3. Add Employee
4. Employee Profile
5. Edit Employee
6. Attendance
7. Leave Management
8. Salaries & Payroll
9. Payslips
10. Departments
11. Performance Reviews
12. Calendar & Events
13. Reports & Analytics
14. Settings
15. 404 page

## Main features

- React Router multi-page navigation
- Responsive desktop, tablet and mobile layouts
- Mobile navigation + slide-out sidebar
- Employee add/edit/delete/profile flows
- Search and filtering
- Attendance status editing
- Leave request creation + approve/reject
- Payroll totals + mark salary as paid
- Printable professional payslip
- Department cards and headcount
- Performance review editing
- Calendar events + approved leave schedule
- Recharts analytics
- CSV report exports
- LocalStorage persistence (no backend needed)
- Demo data reset from Settings

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally `http://localhost:5173`.

## Important

No backend, database, API keys, Firebase or server setup is needed. The application saves changes in browser localStorage so it remains interactive after refresh.
